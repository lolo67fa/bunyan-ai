# Orchestrator

CrewAI-based orchestration of the five agents.

**Owner:** Alanoud

## Planned scope

- Run the workflow: Business Analyst → User Approval → Software Architect → Developer → QA Tester → Project Manager → Preview & Download.
- Pause for user clarification answers and requirement approval.
- Maintain the workflow state for each run.
- Run the QA ↔ Developer repair loop, limited to **two** repair attempts.
- Collect and store artifacts for preview and download.

See [`../../docs/architecture.md`](../../docs/architecture.md) for details.
