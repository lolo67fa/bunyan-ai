# CRUD Template

Reusable HTML/CSS/JavaScript template that the Developer Agent uses to generate CRUD web applications.

**Owner:** Yara

## Planned scope

- `index.html`, `style.css`, `app.js` base structure.
- Create, Read, Update, Delete operations for one or more entities.
- Input validation.
- Persistence with browser `localStorage`.
- Plain HTML, CSS, and JavaScript — no frameworks, no backend.
